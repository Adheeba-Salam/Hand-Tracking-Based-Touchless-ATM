
### Hand Tracking Based Touchless ATM

A computer vision-based ATM interface that enables users to interact
with ATM functions using hand gestures without physically touching
the interface.

## ✨ Features

- Real-time hand tracking
- Touchless gesture-based interaction
- ATM-style user interface
- Gesture-controlled navigation
- Computer vision-based interaction
- Contact-free user experience

## 🛠️ Technologies Used

**Python** • **OpenCV** • **MediaPipe** • **Computer Vision** • **Hand Tracking** 

## 🔄 How It Works

Webcam
  ↓
Hand Detection
  ↓
Hand Landmark Tracking
  ↓
Gesture Recognition
  ↓
Gesture-to-Command Mapping
  ↓
ATM Interface

## 🎯 Objective

To demonstrate how real-time hand tracking and gesture recognition
can be used to create a touchless human-computer interaction system.
